# Contributing / Extending This Repository

This repo is meant to grow with your agency. When you hit a repeatable task not yet covered:

1. Use the skill template from `00-how-to-use/USAGE-GUIDE.md`.
2. Place it in the most relevant numbered folder (create a new numbered folder only if it's a genuinely new phase of the business, not a variant of an existing one).
3. Add it to the table in the root `README.md`.
4. If the skill produces a client-facing deliverable, make sure it references `09-qa-testing/multi-perspective-qa-checklist.md` as a mandatory gate.
5. Log any recurring mistake/pattern you notice in real client work back into the relevant skill's "Premium & QA Notes" section — this repo should get sharper every month, not stay static.

## Versioning Convention
Tag releases as your process matures, e.g. `v1.0` (initial 27-skill set), `v1.1` (added tracking/compliance/incident-response skills). This lets you see how your operating system evolved and roll back if a change doesn't work in practice.
