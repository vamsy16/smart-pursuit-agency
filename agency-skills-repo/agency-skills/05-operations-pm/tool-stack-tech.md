# Tool Stack & Tech Infrastructure

## Purpose
Run a lean, professional tech stack that looks and performs enterprise-grade without enterprise overhead cost — critical for solo/lean-team operators.

## When to Trigger
Agency setup, and quarterly review as needs grow.

## Inputs Required
`[SERVICES_OFFERED]`, `[CURRENT_BUDGET_FOR_TOOLS]`, `[TEAM_SIZE]`

## Execution Prompt
```
Act as an agency operations consultant selecting a tool stack for a
[TEAM_SIZE]-person agency offering [SERVICES_OFFERED], with a monthly tools
budget of [CURRENT_BUDGET_FOR_TOOLS].

Recommend one primary tool (+ 1 budget alternative) for each category:
1. Project management / client portal
2. Proposal & e-signature
3. Invoicing & accounting (India: GST-compliant)
4. Analytics/reporting dashboard (cross-platform)
5. Design/creative collaboration
6. Password/credential sharing (client access security)
7. CRM/pipeline tracking
8. Internal knowledge base (storing these skill files + SOPs + client briefs)

For each, note: monthly cost tier, why it fits a lean/solo operation, and
migration difficulty if outgrown later.
```

## Deliverable Template
Tool Stack Table (Category | Primary Pick | Budget Alternative | Monthly Cost Tier | Why | Migration Notes)

## Premium & QA Notes
A client-facing portal/dashboard (even a simple one) materially changes how "enterprise-grade" you appear versus emailing PDFs and spreadsheets — prioritize this even on a lean budget. Never share client credentials over email/WhatsApp — use a proper password manager with shared vaults.
