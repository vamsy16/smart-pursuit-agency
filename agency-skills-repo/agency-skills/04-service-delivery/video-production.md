# Video Production & Short-Form Content Strategy

## Purpose
Produce scroll-stopping short-form video (Reels/Shorts/TikTok-style) and ad video at a system level — scripts and structure that a freelance editor/videographer can execute against, so you don't need to be the videographer yourself.

## When to Trigger
Monthly content/ad production cycle.

## Inputs Required
`[CLIENT_NAME]`, `[PLATFORM]`, `[VIDEO_PURPOSE]` (brand/ad/educational), `[PRODUCT/OFFER]`

## Execution Prompt
```
Act as a short-form video strategist for [CLIENT_NAME] on [PLATFORM], purpose:
[VIDEO_PURPOSE], product: [PRODUCT/OFFER].

1. Hook Bank: 8 opening lines/visuals designed to stop the scroll in the first
   1.5 seconds, using different angles (pattern interrupt, bold claim,
   question, relatable problem, controversy/contrarian take).
2. For the top 3 hooks, write a full script (hook → build → payoff → CTA)
   with on-screen text cues and suggested shot list for an editor/videographer.
3. Editing Brief: pacing notes (cut frequency), music/sound direction, caption
   style, and platform-specific specs (aspect ratio, length, safe zones).
4. Repurposing Plan: how one produced video gets cut into 3+ additional
   assets (different hooks on same footage, static quote-card excerpts, etc.)
```

## Deliverable Template
Hook Bank (8 options) → 3 Full Scripts with Shot Lists → Editing Brief → Repurposing Plan

## Premium & QA Notes
Test every hook by reading only the first line/seeing only the first frame described — if it doesn't create an immediate reason to keep watching, it's cut, no matter how good the rest of the script is. This is pure Viewer Lens discipline.
