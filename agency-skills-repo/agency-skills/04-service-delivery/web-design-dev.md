# Web Design & Development (Landing Pages, Websites, CRO)

## Purpose
Ship websites/landing pages that convert, not just look good — this is a frequent upsell into ₹1L-5L project fees on top of retainers.

## When to Trigger
New site builds, landing page campaigns, or CRO audits on existing sites.

## Inputs Required
`[CLIENT_NAME]`, `[PAGE_PURPOSE]` (site/landing page/funnel), `[TARGET_AUDIENCE]`, `[PRIMARY_CONVERSION_GOAL]`, existing analytics if available

## Execution Prompt
```
Act as a conversion-focused web strategist/designer for [CLIENT_NAME]. Purpose:
[PAGE_PURPOSE], audience: [TARGET_AUDIENCE], goal: [PRIMARY_CONVERSION_GOAL].

1. Page Structure/Wireframe (section by section): for each section, define
   its single job (e.g., Hero: earn 5 more seconds of attention; Section 2:
   resolve the #1 objection), and the specific content/element it needs.
2. Above-the-fold Copy: headline + subheadline + CTA button text — test 3
   headline variants using different angles (outcome-led, curiosity-led,
   social-proof-led).
3. CRO Checklist: page speed, mobile responsiveness, trust signals (reviews/
   logos/certifications), form friction (fields to remove), and exit-intent
   opportunities.
4. Technical Requirements Doc: recommended stack/CMS, integrations needed
   (CRM, analytics, payment), and a realistic timeline with milestones.
```

## Deliverable Template
Section-by-Section Wireframe Outline → 3 Headline Variants + Hero Copy → CRO Checklist → Technical Requirements & Timeline

## Premium & QA Notes
Every page must pass Viewer Lens testing: show the above-the-fold section to someone unfamiliar with the business for 5 seconds — can they say what it is, who it's for, and what to do next? If not, it fails, regardless of how polished it looks. Never skip real device/speed testing before launch.
