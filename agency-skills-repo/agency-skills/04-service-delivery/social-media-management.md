# Social Media Management & Strategy

## Purpose
Move beyond "posting content" into building an owned audience asset that reduces the client's paid acquisition dependency over time.

## When to Trigger
Monthly content planning cycle + daily/weekly execution.

## Inputs Required
`[CLIENT_NAME]`, `[PLATFORMS]`, `[BRAND_VOICE_NOTES]`, `[TARGET_AUDIENCE]`, `[MONTHLY_THEME/CAMPAIGN if any]`

## Execution Prompt
```
Act as a social media strategist for [CLIENT_NAME] on [PLATFORMS], targeting
[TARGET_AUDIENCE], brand voice: [BRAND_VOICE_NOTES].

1. Content Pillars: define 4-5 content pillars (e.g., Education, Social Proof,
   Behind-the-Scenes, Product, Community) with a % split and the business
   reason for each pillar's weighting.
2. 30-Day Content Calendar: platform | date | pillar | hook/topic | format
   (reel/carousel/static/story) | CTA. Vary formats — do not repeat the same
   post structure more than twice in a row.
3. For 5 highest-priority posts, write full copy + a shot-list/design brief
   for the visual.
4. Community Management SOP: response time targets, tone guide for
   comments/DMs, and escalation triggers (complaints, PR risk).
```

## Deliverable Template
Content Pillar breakdown (with %) → 30-Day Calendar (table) → 5 Full Post Drafts with visual briefs → Community Management SOP

## Premium & QA Notes
Every "hook" line must pass the Viewer Lens: would a real scrolling user stop for the first 1.5 seconds, or does it read like a caption written for the client, not the audience? Test hooks by reading only the first line aloud — if it doesn't create curiosity/tension/value instantly, rewrite it.
