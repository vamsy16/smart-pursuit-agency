# SEO (Technical, On-Page & Content)

## Purpose
Deliver SEO that produces ranking + revenue movement in 90-180 days, backed by a defensible technical process — not "we submit your sitemap and write blogs."

## When to Trigger
Client onboarding (initial audit) + monthly execution cycle.

## Inputs Required
`[CLIENT_WEBSITE]`, `[TOP_5_TARGET_KEYWORDS_OR_TOPICS]`, `[COMPETITOR_URLS]`, current GSC/GA data if available

## Execution Prompt
```
Act as a senior technical SEO consultant auditing [CLIENT_WEBSITE], targeting
[TOP_5_TARGET_KEYWORDS_OR_TOPICS], competing against [COMPETITOR_URLS].

1. Technical Audit Checklist: crawlability, indexation, Core Web Vitals,
   mobile usability, structured data, internal linking — flag likely issues
   based on the site's structure/CMS (note: confirm actual scores with
   PageSpeed Insights / Search Console before reporting to client).
2. Content Gap Analysis: topics/keywords competitors likely rank for that
   [CLIENT_WEBSITE] doesn't cover, based on their visible site structure.
3. 90-Day SEO Roadmap: Month 1 (technical fixes + foundation), Month 2
   (content production + on-page), Month 3 (authority building + internal
   linking + refresh).
4. Content Brief Template for one target keyword — search intent, target
   word count range, required subtopics/headers, internal link targets,
   and a meta title/description (under 60/155 chars).
```

## Deliverable Template
Technical Audit Checklist (with severity: Critical/High/Medium) → Content Gap Table → 90-Day Roadmap (Month | Focus | Deliverables | KPI) → Sample Content Brief

## Premium & QA Notes
Never promise a ranking position or timeline as a guarantee — promise the process and report leading indicators (indexed pages, technical fixes shipped, content published, backlinks earned) alongside lagging indicators (rankings, organic traffic, conversions). Verify all technical claims with actual tools (Search Console, PageSpeed) — AI can structure the audit but cannot see the live site's real Core Web Vitals scores.
