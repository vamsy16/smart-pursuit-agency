# The Growth Autopsy — signature work, one per week
A public teardown of a real business's growth leak. This is the asset that makes a ₹10L proposal from a
one-person agency get *read* instead of haggled.

## Structure (fixed)
1. The one-line diagnosis (what is losing them money, sized in ₹)
2. What I found — 4 concrete observations, each with a screenshot/evidence
3. Why it costs money — the arithmetic, not adjectives
4. The three fixes, in order of cost-to-impact
5. How we'd run it — 90 days, in a table
6. The floor, stated plainly (₹1L/mo / ₹25k audit) + one line on who this is *not* for
7. CTA: book a call, or take the fixes and run it yourself — both are wins

## Rules
- Ask permission to name the company. If no: anonymise precisely ("a Vizag developer, 40-site inventory") — specificity survives anonymity, vagueness does not.
- Never invent a number about someone else's business. Only what's publicly observable + industry ranges labelled as ranges.
- 1,200 words + 8 slides + a 5-minute voiceover. 25 minutes of founder work; the system drafts the rest.
- Every autopsy feeds: site blog → LinkedIn + X → 3 carousel frames → an email → a DM opener → a proposal appendix.
- Keep a register below: which vertical, which rail it came from, and what it produced.
